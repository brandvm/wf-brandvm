Found while checking: the site head code (`docs/handoff/rollback/site-head.html`
line 20) adds `<meta name="robots" content="index,follow,max-image-preview:large">`
to **every** page, so the two noindexed pages carry two conflicting robots
tags. Google applies the stricter one, so they stay noindexed, but other
crawlers may not. Suggested: keep only `max-image-preview:large` in the
site-wide tag (index,follow is the default). That's site custom code
(Site settings → Custom code), so it's for a person in the Designer.

and H1s, and 145 of 149 duplicate descriptions, are `?page=` variants of
the same list pages (page 1 is canonicalised; later pages are separate
URLs by design). Real issues, fixed on staging
(`docs/cms/seo-metadata-fixes.py`, old/new in

| `<h1>` headings inside the body → `<h2>` (the template has the page H1) | 9 posts: telegram-mini-app…, website-structure-expertise…, the-role-of-video-editing…, survive-thrive-risk…, ai-in-digital-marketing…, as-streamers-partner…, cloud-developers-for-hire…, using-domain-intelligence…, top-emerging-it-talent-markets-in-2026 |

All 12 checked on staging.

Not done, with why:

- **Missing description, `/post/top-dallas-logo-design-companies`:** the item
  is a draft that is still live, so a description written now would never
  publish. Same question as the value-proposition post (below).
- **Titles over 60 characters (1,111), descriptions over 155 (810), H1 over
  70 (351):** rewrites of most of the site's copy; a content project, not a
  fix. Google truncates, it doesn't penalise.
- **Images: missing alt text (3,455) and size attributes (5,509):** mostly
  CMS rich-text images. Alt text needs a person or a reviewed generated
  batch; Webflow rich text doesn't write width/height. Separate batch.
- **Security headers (CSP, X-Frame-Options, etc.), `target="_blank"` without
  `noopener`:** review only (the plan says no blanket CSP). Headers can be
  set at Cloudflare, which already fronts the site. Modern browsers imply
  `noopener` for `target="_blank"`.
